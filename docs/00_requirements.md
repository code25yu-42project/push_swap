# Push_swap 요구사항

## 1. 프로젝트 개요
* 주어진 정수들을 스택 2개(`a`, `b`)를 이용해 정렬하는 프로그램을 작성.
* 제한된 명령어 집합으로 최소한의 명령어 수로 정렬 수행.
* 다양한 알고리즘을 이해하고 적합한 방법을 선택하는 능력 필요.
* **출처:** 42 School push_swap(version 8.1)

## 2. 환경 및 규칙
* **언어:** C
* **컴파일:** Makefile 작성, `-Wall -Wextra -Werror` 플래그 사용, `cc` 컴파일러, 재링크 금지
* **라이브러리:** MiniLibX 필수 사용, `libft` 사용 가능
* **메모리:** 할당한 힙 메모리 적절히 해제, 누수 금지
* **에러 처리:** 잘못된 입력이나 오류 발생 시 `"Error\n"` 출력 후 프로그램 종료

## 3. 초기 상태:
  * 스택 `a`: 중복 없는 정수들이 랜덤하게 들어있음
  * 스택 `b`: 빈 상태
* 목표: 스택 `a`를 오름차순으로 정렬 (가장 작은 값이 위에 오도록)
* 스택 `b`는 최종에 빈 상태여야 함

## 4. 허용 명령어 (Push_swap 언어)
* **sa:** 스택 `a`의 상위 2개 원소 스왑 (1개 이하일 땐 무시)
* **sb:** 스택 `b`의 상위 2개 원소 스왑
* **ss:** `sa`와 `sb` 동시에 수행
* **pa:** 스택 `b`의 상위 원소를 `a`로 이동 (빈 경우 무시)
* **pb:** 스택 `a`의 상위 원소를 `b`로 이동
* **ra:** 스택 `a` 모든 원소 위로 1칸 이동 (첫 원소가 마지막으로)
* **rb:** 스택 `b` 모두 위로 1칸 이동
* **rr:** `ra`와 `rb` 동시에 수행
* **rra:** 스택 `a` 모든 원소 아래로 1칸 이동 (마지막 원소가 첫 번째로)
* **rrb:** 스택 `b` 모두 아래로 1칸 이동
* **rrr:** `rra`와 `rrb` 동시에 수행

## 5. 프로그램 요구사항
* 인자로 받은 정수 리스트를 스택 `a`에 넣고 시작 (첫 번째 인자가 스택의 top)
* 최소한의 명령어로 정렬하는 명령어 시퀀스를 출력
* 인자가 없으면 아무 출력 없이 종료
* 에러 시 "Error\n" 출력 후 종료

## 6. 성능
* 500개 숫자 정렬 시 5500명령어 이하로 동작

## 7. 보너스 파트
* **checker 프로그램 작성**
  * 인자로 스택 `a` 초기 상태를 받음
  * 표준 입력으로 명령어 리스트를 읽어 실행
  * 실행 후 스택 `a`가 오름차순 정렬되고 `b`가 비어있으면 "OK\n" 출력, 아니면 "KO\n"
  * 에러 시 "Error\n" 출력
